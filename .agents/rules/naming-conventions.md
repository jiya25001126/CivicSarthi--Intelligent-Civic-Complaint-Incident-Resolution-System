# JanSahay Project & Naming Guidelines

These rules apply across all phases, code, tests, documentation, and UI components.

## 1. Product Name & Branding
- **Official Product Name**: **JanSahay** (used everywhere: UI headers, page titles, README, documentation, package names, logs, API metadata).
- **Prohibited Term**: Under no circumstances use "SamadhanAI" in code, configurations, or UI.
- **CPGRAMS Context Description**: Whenever context regarding CPGRAMS is needed, describe it strictly as:
  > **"JanSahay: AI-assisted grievance resolution layer for CPGRAMS."**
- **Header Tagline**: `"From Complaint to Resolution"`

## 2. Package Names
- Frontend: `jansahay-frontend`
- Backend: `jansahay-backend`
- Mock CPGRAMS Service: `jansahay-mock-cpgrams`

## 3. Legal / Prototype Disclaimer
- Do not imply the project is an official government product.
- **Required Footer Text**:
  > `"JanSahay is a prototype and is not affiliated with or endorsed by DARPG/CPGRAMS."`

## 4. Repository & Branching Conventions
- Repo folder/branch/tag conventions remain:
  - Branches: `phase-N-<feature-or-phase-name>`
  - Tags: `phase-N`
